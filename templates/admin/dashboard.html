CSV/Excel Format Guide
Quick Tips:
  • Only Property Name and Price are required
  • All other columns are optional
  • You can use any column order
  • Column names are case-insensitive (Property, PROPERTY, property all work)

📋 Required Columns

Column Name Required Example
property or property_name ✅ Yes "Sunrise Villa"
price ✅ Yes "50 Lakhs", "1.2 Cr", "25000/mo"

📝 Optional Columns

Column Name Purpose Example
location Property address/area "Sector 17, Chandigarh"
type Listing type "For Sale" or "For Rent"
category Property category "Apartment / Flat", "Villa / Bungalow"
bedrooms Number of bedrooms "3 BHK", "Studio"
area Size in sq ft "1450 sq ft"
status Property status "Active", "Sold", "Rented"

💰 Price Format Examples

  • 50 Lakhs → ₹50,00,000
  • 1.2 Cr → ₹1,20,00,000
  • 25000/mo → ₹25,000 per month (rent)
  • 35000 → ₹35,000
  • 75,00,000 → ₹75,00,000
